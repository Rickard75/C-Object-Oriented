        DUMP INFORMATION

            ./runMass input particle_events.txt ranges massRanges plot massHist_input.root
            ./runMass sim 3000 ranges massRanges plot massHist_sim.root
        PLOT TIME (Necessary specify the lifetime fit parameters)
            ./runTime input particle_events.txt fit particleFitters time timeHist_input.root
            ./runTime sim 3000 fit particleFitters time timeHist_sim.root
        PLOT ALL (Necessary specify the masses ranges and the lifetime fit parameters if the relative analysis mode input is present)
            ./runAll input particle_events.txt ranges massRanges fit particleFitters plot hist_input.root time hist_input.root
            ./runAll sim 3000 ranges massRanges fit particleFitters plot hist_sim.root time hist_sim.root

Summary : 
- one base-analyzer                                 : AnalysisSteering
- two derived-analyzer                              : EventDump e ParticleMass (with ROOT graph for each Particle)
- one base-event                                    : EventSource, SourceFactory
- two derived-event                                 : EventSim, EventReadFromFile
- to compute invariant mass mean                    : MassMean (with ROOT graph)
- to compute invariant mass                         : mass.cc (now DELETED)
- to store costants                                 : Costants
- to store simple functions                         : Utilities  
- to handle events                                  : Event
- to handle input options                           : AnalysisInfo
- to handle generic analyzers                       : AnalysisFactory
- contains code of ex "mass.cc"                     : ParticleReco      
- to handle time graph and calculations             : ParticleLifetime  
- compute proper time using "mass" code + formulas  : ProperTime        
- here does nothing, only add event                 : LifetimeFit       
- contains info about mass ranges                   : massRanges        
- contains info about fitting                       : particleFitters   
- to compute a quadratic fit                        : QuadraticFitter   

- AnalysisFramework : AnalysisFactory, AnalysisInfo, AnalysisSteering, Event, EventReadFromFile, EventSim, EventSource, main, SourceFactory
- AnalysisObjects   : LifetimeFit, MassMean, ParticleReco, ProperTime
- AnalysisPlugin    : EventDump, ParticleLifetime, ParticleMass
- AnalysisUtilities : Costants, QuadraticFitter, Utilities

notes about "mass" stuff:
-       ParticleMass manages the mass of the single particle with ROOT graph
-       MassMean compute mean over all the event of a specific decay (K0 or L0); it is used in ParticleMass
-       mass.cc compute invariant mass of a single decay; it is used in MassMean
